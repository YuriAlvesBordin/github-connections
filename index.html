GitHub Token

Without a token, the GitHub API allows 60 requests/hour. With a personal access token you get 5,000 requests/hour, which lets you explore much larger graphs.

1 Go to github.com/settings/tokens

2 Click Generate new token (classic)

3 Give it a name, no scopes needed for public data

4 Copy the token and paste it below

Your token is stored only in this browser tab's memory and is never sent anywhere except directly to the GitHub API. It is cleared when you close the tab.
